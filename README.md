Entry for the make.fun bounty
[One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488)
— one horror sentence, under 200 characters. Prize $5 USDC, top 10
places (1st $1.54), free entry.

## The line

> I counted thirteen steps to my bedroom every night for ten years, and tonight there were fourteen.

## How it works

`main.py` writes that single line to `/output/entry.txt` and nothing else.
It checks the gate itself first: 1–200 characters, UTF-8, not only white
space. The scare is earned, not announced: a count the narrator has
trusted for ten years is suddenly wrong, and the last word — fourteen —
is the blow. One scene, one twist, nothing after the twist.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
